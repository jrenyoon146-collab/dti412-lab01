# Git Cheat Sheet

## Basic Git Commands

### 1. Check Git Version
```bash
git --version
```

### 2. Configure Username
```bash
git config --global user.name "Your Name"
```

### 3. Configure Email
```bash
git config --global user.email "your-email@example.com"
```

### 4. Initialize a Repository
```bash
git init
```

### 5. Check Repository Status
```bash
git status
```

### 6. Add Files
```bash
git add .
```

### 7. Commit Changes
```bash
git commit -m "Initial commit"
```

### 8. View Commit History
```bash
git log
```

### 9. Clone a Repository
```bash
git clone repository-url
```

### 10. Push Changes to GitHub
```bash
git push origin main
```

### 11. Pull Latest Changes
```bash
git pull origin main
```

### 12. Create a Branch
```bash
git branch branch-name
```

### 13. Switch Branch
```bash
git checkout branch-name
```

### 14. List Branches
```bash
git branch
```

### 15. Connect to GitHub
```bash
git remote add origin repository-url
```

## Conclusion
Git helps developers track changes, manage projects, and work together. GitHub allows developers to store and share their repositories online.
